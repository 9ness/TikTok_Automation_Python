# Learnings

* [Fecha] Contexto: Lección / Resolución
* [2026-05-22] Windows + Python runners crashean en `print("🎙️ ...")` por cp1252 default → `UnicodeEncodeError: 'charmap' codec can't encode characters`. Pasa en cualquier emoji impreso en stdout (locutor.py L134 entre muchos). Fix global: `sys.stdout.reconfigure(encoding="utf-8", errors="replace")` al arrancar `src/api/main.py`, antes de imports pesados. Coste de la tarea afectada: 0 (el crash es ANTES de cualquier API call de pago — solo Gemini previo).
* [2026-05-22] Webhook listener se colgaba cada 24-48h. Root cause: `HTTPServer` single-threaded → cualquier conexión lenta (scanner de puertos, GitHub timeout, etc.) bloquea TODAS las requests siguientes; el proceso sigue "active" para systemd pero `/health` da timeout. Fix: `ThreadingHTTPServer` + `daemon_threads=True`. Safety net: `tiktok-webhook-healthcheck.timer` cada 2 min hace `curl --max-time 5 /health || systemctl restart tiktok-webhook`. Solo reinicia el LISTENER (proceso de 11MB en :9000) — los Docker containers tiktok-api/web/caddy son procesos separados, los jobs corriendo no se enteran.
* [2026-05-22] TikTok Shop URL share `vm.tiktok.com/XXXX` redirige a `www.tiktok.com/view/product/{id}?og_info={...JSON-encoded...}&share_region=ES`. El `og_info` trae title + image LIMPIO sin necesidad de scrape JS. Parser en `url_scraper.py:_extract_tiktok_share_params` saca de los query params con `urlparse` + `json.loads(unquote(...))`. Bypassa por completo el bot-detection del HTML de TikTok.
* [2026-05-22] TIKTOK_SHOP_URL_PATTERN debe aceptar cualquier subdominio: `^https?://([\w-]+\.)*tiktok\.com(/.*)?$`. La versión vieja solo aceptaba `www.` y `shop-xx.` y rechazaba `vm.tiktok.com` de los share URLs.
* [2026-05-22] Seedance i2v Atlas: `TIER_DURATION_LIMITS` (config.py) → mín 4s por clip en standard/advanced/pro. Para vídeos <8s solo cabe single_shot. Para ≥8s puede ser multi (2×4s, 4+5, etc.). `strategy="dynamic"` rota fotos (`rotate`) entre clips, `cinematic` no. Pro tier (ref2v) es 1 prompt único con multi-shot INTERNO (hasta 9 refs). Veo 3 nativo 1 toma 10s max.
